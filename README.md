# Kaze TV 風 — versions publiées

Lecteur IPTV pour Android, Android TV, Google TV et Fire TV (portails Stalker / MAG, Xtream Codes, playlists M3U).

Ce dépôt ne contient que les **versions publiées** de Kaze TV.

## Installer

1. Ouvrez la dernière version dans **[Releases](../../releases/latest)**.
2. Téléchargez **`KazeTV-vX.Y.Z.apk`** et installez-le sur l'appareil (Downloader, clé USB, ou `adb install`).

## Mettre à jour

Kaze TV vérifie lui-même s'il existe une nouvelle version et propose de l'installer
(Réglages › À propos › Rechercher une mise à jour). Vos réglages sont conservés.

## Gestion à distance des TV (facultatif)

Pour régler depuis un PC Windows les playlists, adresses MAC, guides et groupes des TV de vos proches :
téléchargez **`KazeTV-Gestionnaire-vX.Y.Z.zip`**, décompressez-le et lancez
**`Installer le Gestionnaire Kaze TV.bat`**. Le guide complet est inclus dans le zip.
